# Ficha de efecto: cifra-que-cuenta

- **id:** X04
- **familia:** Texto
- **nombre:** cifra-que-cuenta
- **qué hace:** Un número sube hasta su valor final.

## Parámetros básicos

| Parámetro | Valor por defecto | Unidad | Desviaciones (motivo) |
|---|---|---|---|
| valor inicial | 0 | — |  |
| duración | 30 | frames |  |
| curva | ease-out | — |  |
| decimales | sólo si el dato los necesita | — |  |
| color | acento del tema | — |  |

## Cuándo usarlo

- Un dato que sostiene el argumento.
- No usar cuando: si el número cambia después de aparecer, o si son varias cifras a la vez.
