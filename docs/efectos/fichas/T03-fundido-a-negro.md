# Ficha de efecto: fundido-a-negro

- **id:** T03
- **familia:** Transiciones
- **nombre:** fundido-a-negro
- **qué hace:** Cierra un bloque a negro y abre el siguiente desde negro.

## Parámetros básicos

| Parámetro | Valor por defecto | Unidad | Desviaciones (motivo) |
|---|---|---|---|
| duración de salida a negro | 10 | frames |  |
| duración de entrada desde negro | 10 | frames |  |
| curva | ease-in-out | — |  |

## Cuándo usarlo

- Cierre de un bloque o del reel.
- No usar cuando: entre planos seguidos: corta el ritmo.
