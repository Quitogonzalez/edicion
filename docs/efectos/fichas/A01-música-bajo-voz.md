# Ficha de efecto: música-bajo-voz

- **id:** A01
- **familia:** Audio
- **nombre:** música-bajo-voz
- **qué hace:** La música baja cuando hay voz (ducking).

## Parámetros básicos

| Parámetro | Valor por defecto | Unidad | Desviaciones (motivo) |
|---|---|---|---|
| nivel base | −18 | dB |  |
| nivel con voz | −28 | dB |  |
| ataque | 100 | ms |  |
| liberación | 600 | ms |  |

## Cuándo usarlo

- Siempre que haya música de fondo y voz.
- No usar cuando: en pasajes de música sin voz: no hay nada que bajar.
