# Ficha de efecto: cámara-lenta

- **id:** C05
- **familia:** Cámara
- **nombre:** cámara-lenta
- **qué hace:** Baja la velocidad para remarcar un gesto.

## Parámetros básicos

| Parámetro | Valor por defecto | Unidad | Desviaciones (motivo) |
|---|---|---|---|
| velocidad | 0.6 | × |  |
| rampa de entrada | 12 | frames |  |
| rampa de salida | 12 | frames |  |

## Cuándo usarlo

- Un gesto o una palabra que pesa.
- No usar cuando: más de una por idea, o en cada frase.

## Costo de render

Pendiente. Medir en el Mac con el reel de prueba común a todos los efectos: tiempo de render con el efecto y sin él, en segundos.
