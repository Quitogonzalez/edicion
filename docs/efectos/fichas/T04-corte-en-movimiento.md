# Ficha de efecto: corte-en-movimiento

- **id:** T04
- **familia:** Transiciones
- **nombre:** corte-en-movimiento
- **qué hace:** Corta en el pico de un gesto o un paneo para que la imagen parezca continua.

## Parámetros básicos

| Parámetro | Valor por defecto | Unidad | Desviaciones (motivo) |
|---|---|---|---|
| punto de corte | frame de mayor movimiento del gesto o paneo | — |  |
| duración | 0 | frames |  |

## Cuándo usarlo

- Un gesto o un paneo que cruza de un plano a otro.
- No usar cuando: si no hay movimiento claro en el punto de corte.
