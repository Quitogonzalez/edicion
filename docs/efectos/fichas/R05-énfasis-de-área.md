# Ficha de efecto: énfasis-de-área

- **id:** R05
- **familia:** Recursos encima
- **nombre:** énfasis-de-área
- **qué hace:** Marca una zona de la pantalla con un trazo fino.

## Parámetros básicos

| Parámetro | Valor por defecto | Unidad | Desviaciones (motivo) |
|---|---|---|---|
| trazo | 3 | px |  |
| color | acento del tema | — |  |
| radio de esquina | 24 (radio del tema) | px |  |
| entrada y salida | 8 | frames |  |
| brillo | ninguno | — |  |

## Cuándo usarlo

- Señalar una zona concreta de una captura o de un plano.
- No usar cuando: si la zona ya es obvia, o si hay más de una marca a la vez.

## Costo de render

Pendiente. Medir en el Mac con el reel de prueba común a todos los efectos: tiempo de render con el efecto y sin él, en segundos.
